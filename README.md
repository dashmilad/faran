# فرم هزینه فاران — React

نسخه آماده فرم «صورت ریز هزینه‌های تنخواه واحد خدمات» بر اساس تصویر مرجع ارسالی.

## امکانات
- ورود اطلاعات ۸ ردیف هزینه
- ستون‌ها: تاریخ، محل مراجعه (بانک/شرکت)، نوع خدمات، شماره قرارداد/فاکتور، شرح هزینه، مبلغ هزینه
- محاسبه خودکار جمع کل
- ویرایش کد سند، کد سند مرجع، عنوان و تاریخ
- ثبت نام امضاکنندگان
- چاپ مستقیم با چیدمان A4 افقی
- خروجی PDF با دکمه مستقل
- راست‌چین و مناسب فارسی

## اجرا
نیاز به Node.js دارد.

```bash
npm install
npm run dev
```

سپس آدرس نمایش‌داده‌شده توسط Vite را باز کنید.

برای ساخت نسخه نهایی:

```bash
npm run build
```

فایل‌های خروجی داخل `dist` قرار می‌گیرند.
